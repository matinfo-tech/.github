## What we build

Matinfo Tech develops practical software, tools and open-source projects designed to solve real-world engineering challenges.

We combine software engineering, security, user experience and modern development practices to create solutions that are reliable, maintainable and genuinely useful.

Our work focuses on three complementary areas.

### Developer Tools & Productivity

Tools that improve development workflows, simplify complex tasks and make engineering more efficient.

- Developer tooling and CLI applications
- Automation and workflow integration
- Documentation and publishing solutions
- Modern JavaScript and TypeScript ecosystems

### AI, Privacy & Security

Building safer ways to integrate artificial intelligence into everyday workflows without compromising sensitive information.

- Privacy-first AI integrations
- Personally identifiable information (PII) protection
- Secure AI workflows and integrations
- Data anonymization and security tooling

### Web Engineering & Documentation

Lightweight, reusable solutions for modern web applications and technical documentation.

- Vue.js, TypeScript and Node.js
- VitePress plugins and extensions
- Interactive documentation components
- Reusable libraries and developer experiences

## Engineering principles

We believe good software is more than code that works.

Our approach is guided by a few principles:

- **Quality over quantity** — Focus on useful features, thoughtful architecture and maintainable code.
- **Privacy by design** — Treat data protection and security as engineering requirements, not afterthoughts.
- **Simplicity matters** — Prefer focused solutions, clear interfaces and minimal complexity.
- **Open by default** — Share knowledge, contribute to the ecosystem and build on open standards.
- **Developer experience** — Make software intuitive to use, integrate and maintain.
- **Continuous improvement** — Embrace automation, testing, code quality and modern engineering practices.
